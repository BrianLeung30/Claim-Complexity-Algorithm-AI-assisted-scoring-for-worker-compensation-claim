# Claims Complexity Algorithm

## Project summary

This project will develop an artificial intelligence system for analyzing insurance claims. The system will produce two primary outputs: a claim complexity score, representing the expected difficulty of processing a claim, and an expected payout, estimating the potential financial cost of the claim.
The system will consist of machine learning models, a web-based interface, and an API. Customers and insurance employees will use the web interface, while insurance companies will be able to integrate the system into larger applications through the API. The system is intended to provide data-driven decision support rather than replace the judgment of insurance professionals.
